Now here's your complete step-by-step guide:

The Actual Problem
electron-builder downloads Mac signing tools that contain Unix symlinks. Windows blocks symlink creation for normal users. The fix is a one-time Windows setting change.

Step 1 — Enable Symlink Creation (do this once, then never again)
If you have Windows 10/11 Pro or Enterprise:

Press Win+R, type secpol.msc, hit Enter
Navigate to: Local Policies → User Rights Assignment
Double-click "Create symbolic links"
Click Add User or Group → type your Windows username → OK
Reboot your PC
If you have Windows Home (no secpol.msc):

Just right-click VS Code in Start menu → Run as Administrator every time you build. That's your only option on Home edition.
Step 2 — Generate SSL Certs (one-time, needed for phone camera access)
In your terminal from inside my-desktop-app:

powershell
mkdir src\server\certs
Then run this one long command (replace the IP with your actual Wi-Fi IP — find it with ipconfig):

powershell
openssl req -x509 -newkey rsa:2048 -keyout src/server/certs/key.pem -out src/server/certs/cert.pem -days 365 -nodes -subj "/CN=192.168.1.XXX"
Step 3 — Add a cert-gen script to package.json
Open package.json and add this to your "scripts" section:

json
"gen-certs": "node -e \"const {execSync}=require('child_process'); const ip=require('os').networkInterfaces(); console.log('Run openssl manually with your IP from ipconfig')\""
Step 4 — Place your frontend HTML
Copy your test.html (the barcode scanner page) to:

src/server/frontend/index.html
Step 5 — Update the files in VS Code (open each, paste, Ctrl+S)
electron-builder.yml → use the YAML artifact above (completely replace)
src/main/index.js → use the index.js artifact above (completely replace)
src/server/inventoryServer.js → create this new file, paste the inventoryServer artifact
Step 6 — Build
powershell
Remove-Item -Path "$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign" -Recurse -Force -ErrorAction SilentlyContinue
npm run build:win
Step 7 — Install & Run
powershell
Invoke-Item dist\
Double-click MyDesktopApp Setup.exe → UAC prompt → Yes → installs with desktop shortcut automatically.

What happens when someone opens the installed app:

Windows UAC prompts for admin (because of requestedExecutionLevel: requireAdministrator in the YAML)
Hotspot turns on automatically with SSID MyDesktopAppHotspot / password Password123
Express API starts on port 5000
HTTPS inventory server starts on port 3000
Phones connect to the hotspot then browse to https://192.168.X.X:3000 (they'll get a certificate warning first time — tap "Advanced → Proceed")

Asta Centrifugal Frontier - Desktop App
An autonomous, self-configuring desktop application built with Electron, Vite, and React. The application functions as a standalone edge server that turns the host computer into a localized network infrastructure hub.

Upon launch, the app automatically executes elevated administrative tasks to host a localized Wi-Fi Hotspot network, spins up an integrated HTTPS backend server, and hosts an offline web portal accessible to any mobile device connecting to its hotspot broadcast.

🚀 System Architecture & Core Concept
This application bypasses any external network dependencies or third-party mesh tunnels (such as Tailscale). It treats the host machine as an completely isolated local server environment:

Autonomous Initialization: On booting up, the application claims an administrative role to automatically toggle and share the native operating system's localized Wi-Fi hotspot access point without requiring direct human configuration.

The Unified Backend Server: A streamlined backend server initializes immediately after the network infrastructure is ready. It handles two tasks simultaneously:

Serves the pre-compiled React frontend client bundle directly to incoming mobile requests.

Exposes structural API routes allowing client devices to make runtime calls to read and write directly to a local, high-speed database consisting of structured JSON object arrays.

The Mobile Portal Experience: External smartphones connect explicitly to the machine's local Wi-Fi channel. By typing the computer's active IP address into an HTTPS browser link (https://<host-wifi-ip>), clients pull the system UI directly from your app server to write or process structural logic securely.

To ensure the packaging utilities and internal automation scripts execute correctly across different host permissions, complete the following local settings.

1. Developer Tooling Symbolic Link Privileges (Windows Only)
If building or packaging this desktop utility on Windows, compilation binaries must be granted permission to map structural symlinks within the OS environment:

For Windows 10/11 Pro or Enterprise:

Press Win + R, type secpol.msc, and press Enter.

Navigate to: Local Policies ➔ User Rights Assignment.

Locate and double-click "Create symbolic links".

Click Add User or Group... and enter your explicit machine user profile identity (e.g., DESKTOP-NCUORNL\User).

Click OK, apply changes, and reboot your computer.

For Windows Home Edition:

Because secpol.msc is unavailable on standard Home distributions, you must explicitly launch your developer terminal or IDE environment by right-clicking its icon and choosing "Run as Administrator" every single time you execute builds.
